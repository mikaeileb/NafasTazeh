# نفس تازه | Nafas Tazeh

اپلیکیشن فارسی اندروید برای ترک تدریجی سیگار.

- رابط فارسی و تاریخ شمسی
- ثبت مصرف روزانه و نمودار پیشرفت
- برنامه کاهش تدریجی شخصی‌سازی‌شده
- مدیریت وسوسه و شمارش روزهای بدون سیگار
- پس‌انداز هزینه سیگار و یادآورها

پروژه با GitHub Actions برای ساخت APK پیکربندی شده است.
