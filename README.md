# نفس تازه | Nafas Tazeh

اپلیکیشن فارسی اندروید برای همراهی در مسیر کاهش و ترک سیگار.

## امکانات
- پرسش‌های شروع و ساخت مسیر شخصی بر اساس مصرف روزانه، سابقه و هزینه پاکت
- انتخاب کاهش تدریجی تا روز صفر یا تعیین روز مشخص برای قطع
- ثبت مصرف روزانه، اصلاح آخرین ثبت و تأیید روز بدون سیگار
- نمایش روزهای پاک پیاپی، تعداد سیگارهای کمترشده و صرفه‌جویی تقریبی به تومان
- گزارش ۷ روز اخیر با نمودار و سابقه بر اساس تاریخ شمسی
- ثبت محرک‌ها و شدت وسوسه، همراه با تایمر ۱۰ دقیقه‌ای و پیشنهادهای فوری
- یادآور روزانه اندروید و ذخیره نسخه پشتیبان JSON
- ذخیره داده‌ها روی خود دستگاه؛ بدون نیاز به حساب یا اینترنت
- آیکون برداری Adaptive Launcher با حاشیه امن برای شکل‌های مختلف لانچر

## ساخت APK
پس از هر Push به شاخه \`main\`، یا با اجرای دستی Workflow:
1. به زبانه **Actions** مخزن برو.
2. گردش‌کار **Build Nafas Tazeh APK** را باز کن.
3. پس از پایان موفق، Artifact به نام **NafasTazeh-APK** را از همان اجرای Workflow دریافت کن.
4. فایل ZIP مربوط به Artifact را باز و \`app-debug.apk\` را روی گوشی نصب کن.

## فناوری
- Android / Kotlin
- WebView محلی با HTML، CSS و JavaScript
- Gradle 8.9، Android Gradle Plugin 8.7.3، JDK 17

## نکته سلامت
این اپ ابزار پیگیری و پشتیبانی رفتاری است و جایگزین توصیه پزشکی نیست. برای انتخاب روش درمان وابستگی به نیکوتین، از پزشک یا داروساز راهنمایی بگیر.
